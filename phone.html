내 폰 문자를
OW INBOX에 연결하기

한 번만 설정하면 이 폰에 오는 문자가 PC의 OW INBOX에 바로 떠요.

연결 정보가 없는 링크예요. 처음 받은 QR이나 링크로 다시 열어주세요.
1
문자 전달 앱 설치

무료 오픈소스 앱 SMS to URL Forwarder예요. 문자 권한 정책 때문에 Play 스토어에는 없어서 공식 배포처(F-Droid)에서 받아요.

앱 다운로드 (APK)

다운로드 후 파일을 눌러 설치하세요. "출처를 알 수 없는 앱" 안내가 나오면 이 출처 허용을 켜주세요.

2
내 전용 주소 복사

아래 버튼을 누르면 주소가 복사돼요.

3
앱에서 규칙 추가

앱을 열고 문자 권한을 허용 → 오른쪽 아래 + 누르기

Sender: * (모든 문자)
Webhook URL: 복사한 주소 붙여넣기
나머지: 그대로 두고 저장
4
꺼지지 않게 설정

설정 → 애플리케이션 → SMS to URL Forwarder → 배터리 → 제한 없음

기본 메시지 앱에서 '채팅+(RCS)'로 온 메시지는 전달되지 않아요. 일반 문자만 전달돼요.

1
내 전용 주소 복사
2
단축어 앱 → 자동화

아래 자동화 탭 → 새로운 자동화 → 메시지
보낸 사람은 비워두고 → 즉시 실행 → 다음 → 새로운 빈 단축어

3
"URL 콘텐츠 가져오기" 추가

동작 검색에서 URL 콘텐츠 가져오기를 추가하고 설정하세요.

URL: 복사한 주소
방법: POST · 요청 본문: JSON
키 from → 값: 단축어 입력 → 보낸 사람
키 text → 값: 단축어 입력 → 내용

iOS 17 이상에서 "즉시 실행"이 돼요.

연결 테스트
